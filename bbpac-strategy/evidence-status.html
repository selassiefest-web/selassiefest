Evidence & Verification Status

Everything the Gate 0 Recognition Dossier needs, tracked in the open — including the items that are not done yet. A campaign asking a government body for "no stones unturned" scrutiny has to apply that same standard to itself first.

Related: the Park-Number Administrative Paper Trail

The seven-question investigation into how CPD creates, splits, merges, and retires Park Numbers lives on the Precedent Library page (it's a precedent-verification question, not a dossier-assembly task, so it's tracked there rather than duplicated here). As of this system's creation, question 7 — a complete post-1934 CPD action splitting one park number into two — remains the single highest-priority open item in the entire campaign.

How to keep this page honest

Update assets/data/evidence.json the moment an item's status changes — do not let this page go stale while decks built from it stay in circulation. If an item moves to "Confirmed," check whether any deck that references it needs its own verification note updated to match.
