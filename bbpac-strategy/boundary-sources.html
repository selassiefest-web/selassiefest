Boundary & GIS Sources

63rd Street Beach / Jackson Park Historic Landscape District — boundary data, GIS sources, acreage reconciliation, and current land-use proposals. Version 2, updated August 9, 2026: cross-checked against a second, independently produced source document, with every link re-tested the same way.

What changed in this version

This is an updated edition, produced after cross-checking this page's original source list against the organizing committee's separate "Source-of-Truth Research Framework." Every source unique to that framework was tested the same way the first batch was: fetched directly where possible, or checked against an independent cross-reference where a site blocks automated access. Three things came out of that pass:

  1. Two links proved better than what this page used before, and have replaced them (the NRHP record, the Chicago Landmarks pavilion record).
  2. One factual figure in the reconciliation table — Jackson Park's total acreage — traces to a genuine ambiguity in CPD's own web copy, flagged below so it doesn't get repeated as fact.
  3. One spatial identifier (the OpenStreetMap object for the 63rd Street Beach Dunes) is given differently by the two source documents and could not be resolved by either search or direct fetch. It is flagged as unresolved rather than guessed at.

The acreage trap — read this before citing "Jackson Park's acreage" anywhere

CPD's own Jackson (Andrew) Park facility page states in one sentence that "Jackson Park totals 551.52 acres" and a few sentences later says Olmsted and Vaux "were hired to lay out the 1055-acre park," using "the park" both times without distinguishing the original three-park South Park system from present-day Jackson Park alone. Use 551.5 acres for Jackson Park's own size. The 1,055-acre figure is the combined 1869–71 South Park Commission charge (Jackson Park + Washington Park + the Midway Plaisance together) and should only appear clearly labeled as such.

Unresolved: OpenStreetMap object for the 63rd St. Beach Dunes

Two different source documents give two different object types and IDs for the same feature: Relation 20660684 vs. Way 1137357736. Neither could be confirmed by search or automated fetch (OSM blocks bots). Do not cite either as settled — open both directly in a browser and confirm before either appears in NP-02 or any Council document.

Closing note

Merging the two source lists did not surface any outright contradictions about the facts that matter most to the Council's position — the 19.3-acre OPC site figure, the Jackson Park Historic Landscape District's 1972 NRHP listing, and the location and history of the 63rd Street Beach Dunes all hold up consistently across every independent source checked. The two open items above — the Jackson Park acreage phrasing and the OSM object ID for the dunes — are exactly the kind of small, specific discrepancies worth resolving before either document is cited publicly, precisely because they are the kind of thing an opposing party would seize on if left unreconciled.

This source list is what NP-02 (Jurisdiction & Boundary Map) on the public site will be drawn from, once the boundary itself is drafted and the two open items above are resolved.
