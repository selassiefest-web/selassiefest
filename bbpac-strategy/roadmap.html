Why 501(c)(3) formation starts on Day 1, not after Gate 0

Forming the nonprofit corporation and filing for tax exemption doesn't depend on CPD's classification decision at all — it can and should start immediately, in parallel with Track A and Track B, because IRS processing time is the longest single clock in this whole roadmap. The same bylaws you adopt for the nonprofit corporation double as the bylaws CPD requires in Phase 1, so that work isn't duplicated. If the 501(c)(3) determination is still pending when you reach Phase 1, use Chicago Parks Foundation's fiscal sponsorship as the bridge — CPD's process doesn't wait on the IRS, and neither should your fundraising.

Where the "singular focused path" actually is

There is exactly one hard sequential spine: Gate 0 determination → Phase 1 (Letter of Intent through registration) → Phase 2 (recognition confirmed) → Phase 3 (operate). Everything else — community organizing, evidence-gathering, the Alderman's sponsorship, JPAC coordination, and 501(c)(3) formation — is a parallel branch that either feeds evidence into the spine or removes a future bottleneck (fundraising capacity) before it's needed. None of the parallel branches block each other; only the Gate 0 decision gate blocks entry into Phase 1.
