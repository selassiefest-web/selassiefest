ID Checker / Bar Security

📢 Position Open – Shared with Festival Security

Email: selassiefest@gmail.com with subject "ID Checker Application"

Position Overview

The ID Checker is the first line of defense for legal alcohol service at Selassiefest. This role verifies that every customer entering the bar area is 21 or older and possesses a valid government‑issued ID. ID Checkers report to the Bar Manager and work alongside festival security personnel.

Key Responsibilities

  • Stand at bar entrance and check every customer's ID before they approach the bar.
  • Refuse entry to anyone under 21 or without valid ID.
  • Recognize signs of fake or altered IDs; escalate suspicious IDs to Bar Manager or security.
  • Apply wristbands or hand stamps to verified customers (if used).
  • Politely deny service to visibly intoxicated persons attempting to re‑enter.
  • Communicate with bar staff about denied entries or crowd issues.
  • Assist with crowd flow and line management at bar entrances.

Qualifications

  • Must be at least 21 years old (to handle age verification credibly).
  • Ability to stand for full shift and work outdoors.
  • Firm but polite communication skills.
  • Attention to detail – able to spot ID inconsistencies.
  • No prior security experience required; training provided.

Reporting & Collaboration

  • Reports to: Bar Manager
  • Works with: Festival security team, bartenders, barbacks

📌 Quick Facts

  • 📅 Status: Open (shared with security team)
  • 📧 Contact: selassiefest@gmail.com
  • ⏰ Commitment: Event days only (shifts available)
  • 💰 Compensation: Paid hourly (may be combined with general security shifts)
  • 🎯 Key Metrics: No underage service, low conflict rate

🪪 Acceptable IDs

  • U.S. driver's license (all states)
  • U.S. passport or passport card
  • U.S. military ID
  • State‑issued non‑driver ID
  • Foreign passport (must be valid)

❌ Unacceptable IDs

  • Photo of ID on phone
  • Expired ID (even if otherwise valid)
  • School ID, work ID
  • Birth certificate

📋 ID Checker Training (30 minutes before event)

  • How to check for holograms, UV features, and expiration dates.
  • Common fake ID indicators (wrong font, bumpy texture, mismatched photos).
  • Script for polite refusal: "I'm sorry, I cannot accept this ID. You must be 21 with a valid ID to enter."
  • When to call security – don't engage in arguments.
  • Wristband or stamp protocols (if used).

🛡️ Handling Difficult Situations

  • Remain calm and firm. Do not yell or insult.
  • If a customer argues, repeat once: "I cannot let you in without valid ID."
  • If they persist, step back and call security via radio.
  • Never touch a customer or their ID forcefully.
  • Note: Visible intoxication = deny entry even if ID is valid.

📢 Radio Communication (with Bar Manager & Security)

  • "ID Checker to Bar Manager – need backup at entrance, line is backing up."
  • "ID Checker to Security – customer refusing to leave, please assist."
  • "All clear – entrance under control."

To apply for ID Checker: Email selassiefest@gmail.com with "ID Checker Application" in the subject line. Include any security or customer service experience (not required).

This role can be combined with general festival security shifts – please specify interest.
